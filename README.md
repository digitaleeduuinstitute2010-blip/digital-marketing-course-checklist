# digital-marketing-course-checklist
A practical checklist for freshers to evaluate AI digital marketing courses: syllabus, trainers, projects, fees and placement claims.
## Why this exists

Almost every institute calls itself "the best" and now adds "AI" to the course name. This checklist helps you separate courses that build skills and portfolios from courses that only hand out certificates.

## Quick checklist

- [ ] Fundamentals (SEO, ads, analytics) come before advanced AI tools
- [ ] AI is taught inside every module, not as one last chapter
- [ ] Trainers can show recent live work
- [ ] You get your own tool logins and your own project
- [ ] At least three portfolio projects by the end
- [ ] Placement support is described in writing, with no job guarantee
- [ ] Fee breakdown is clear (tools, certification, GST)
- [ ] A free demo class is available
- [ ] Batch size is small enough for personal feedback
- [ ] Syllabus can be downloaded

## 1. Syllabus

| Module | You should be able to |
|---|---|
| SEO and GEO | Rank a page and structure it so AI search engines can quote it |
| Content marketing with AI | Use AI for drafts, then edit into something human |
| Google and Meta Ads | Launch a live campaign with a small real budget |
| Analytics (GA4) | Read a report and explain what to change |
| Email and WhatsApp automation | Build a basic funnel with automated follow-ups |
| Social media strategy | Plan a 30-day calendar tied to a goal |

**Warning sign:** a syllabus that lists thirty tools but no outcomes.

## 2. Trainers

Ask to see recent live work: a ranking site, a running ad account or a client case study (client details can be hidden). Practitioners tell stories. Textbook trainers give definitions.

## 3. Hands-on practice

You should personally practice with tools in four areas:

| Area | Examples |
|---|---|
| Writing and research | ChatGPT, Gemini, Perplexity |
| Design | Canva, Figma |
| SEO and data | Google Search Console, GA4, a keyword tool |
| Automation | Zapier, Make, an email platform |

Ask: **"Will I have my own login and my own project?"** Shared demo accounts teach very little.

## 4. Placement support

No honest institute can guarantee a job. Look for:

- Resume and portfolio review
- Mock interviews
- Named hiring partners
- A chance to speak with a past student
- A written statement of what happens if you are not placed

## 5. Fees

Ask what is included: tools, certification, projects, study material and GST. Compare the **total cost** with what you actually get. A cheaper course that only gives a certificate is rarely better value.

## 6. Green flags and red flags

| Green flag | Red flag |
|---|---|
| Free demo class | "Offer ends today" pressure |
| Live projects or ad budgets | Only slides and recorded videos |
| Small batches | 50 to 60 students in one room |
| Trainers with visible recent work | No online footprint |
| Honest placement language | "100% job guarantee" |
| Downloadable syllabus | Verbal-only course details |

Two or more red flags: walk away.

## Questions to ask in a demo class

1. Which campaign have you run in the last six months?
2. What went wrong, and how did you fix it?
3. Can I see a results dashboard with client details hidden?
4. Will I have my own tool logins and project?
5. What exactly is included in the fee, in writing?
6. Can I speak to a past student?
